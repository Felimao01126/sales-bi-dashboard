# SalesBI — Projeto de Software

Projeto de BI desenvolvido para a matéria Projeto de Software.

## AC1
- Dashboard com visão geral das vendas
- Faturamento total
- Quantidade de vendas
- Faturamento por mês

## AC2
- Análise de faturamento por produto
- Gráfico de faturamento por produto

- ##AC3
- Página de análise de vendas
- Indicador de quantidade total vendida
- Gráfico de quantidade vendida por produto

- Prova Final
- Consolidação das funcionalidades desenvolvidas nas AC1, AC2 e AC3
- Dashboard com indicadores e gráficos de vendas
- Modelo lógico de dados (MER) baseado na estrutura do arquivo CSV

## Ferramentas
- Power BI
- GitHub
- Base de dados em CSV
